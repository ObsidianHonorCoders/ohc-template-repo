# CMake Options and Configuration

This reference documents all CMake options available when configuring
the OHC template project.

## Build Configuration

### CMAKE_BUILD_TYPE

Set the build type (generator-independent mode).

```bash
# Debug build with symbols and no optimization
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug

# Release build with optimization and no symbols
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

# RelWithDebInfo: optimized with debug symbols
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
```

**Default**: Debug (via presets)

**Note**: Multi-config generators (MSVC, Xcode) ignore this; use
build configuration during build instead.

## Testing Options

### BUILD_TESTING

Enable or disable unit and integration tests.

```bash
cmake -S . -B build -DBUILD_TESTING=ON   # Run tests
cmake -S . -B build -DBUILD_TESTING=OFF  # Skip tests
```

**Default**: ON
**Presets**: dev and ci both enable this

**Related**: Use `ctest` to run tests after build:
```bash
cmake --build build
ctest --preset dev-test --output-on-failure
```

## Code Quality Options

### OHC_ENABLE_WERROR

Treat compiler warnings as errors. Enforces clean compilation.

```bash
# Enable: warnings become errors (default in template)
cmake -S . -B build -DOHC_ENABLE_WERROR=ON

# Disable: warnings only, no failure
cmake -S . -B build -DOHC_ENABLE_WERROR=OFF
```

**Default**: ON
**Rationale**: Prevents warning accumulation; catch issues early

**Use when**: Relaxing for experimental code or legacy warnings:
```bash
cmake -S . -B build -DOHC_ENABLE_WERROR=OFF \
  -DCMAKE_BUILD_TYPE=Debug
```

## Analysis and Profiling

### ENABLE_SANITIZERS

Enable AddressSanitizer (memory errors), UndefinedBehaviorSanitizer
(UB detection), and frame pointers for debugging.

```bash
cmake -S . -B build -DENABLE_SANITIZERS=ON
```

**Default**: OFF
**Supported**: GCC and Clang only (not MSVC)
**Impact**: ~2x slowdown, requires rebuild
**Use when**: Hunting memory leaks or undefined behavior

**Example**:
```bash
cmake -S . -B build -DENABLE_SANITIZERS=ON \
  -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/bin/ohc_template_app  # Sanitizer output to stderr
```

### ENABLE_COVERAGE

Enable code coverage instrumentation via `--coverage` flag
(instrumented branches and calls).

```bash
cmake -S . -B build -DENABLE_COVERAGE=ON
```

**Default**: OFF
**Supported**: GCC and Clang only (not MSVC)
**Tools**: Use `lcov` or `gcov` to analyze coverage

**Example**:
```bash
cmake -S . -B build -DENABLE_COVERAGE=ON
cmake --build build
ctest --preset dev-test
lcov --directory build --capture --output-file coverage.info
```

## Documentation

### BUILD_DOCS

Build API documentation with Doxygen.

```bash
cmake -S . -B build -DBUILD_DOCS=ON
```

**Default**: OFF (docs not generated by default)
**Requires**: Doxygen installed
**Output**: `build/html/index.html` (see generated docs)

**Example**:
```bash
cmake -S . -B build -DBUILD_DOCS=ON
cmake --build build --target docs
open build/html/index.html
```

## Compiler and Generator Selection

### CMAKE_CXX_COMPILER

Explicitly select the C++ compiler.

```bash
# Use Clang instead of default
cmake -S . -B build \
  -DCMAKE_CXX_COMPILER=clang++ \
  -DCMAKE_C_COMPILER=clang

# Use specific GCC version
cmake -S . -B build \
  -DCMAKE_CXX_COMPILER=g++-11 \
  -DCMAKE_C_COMPILER=gcc-11
```

### CMAKE_GENERATOR

Explicitly select CMake generator.

```bash
# Ninja (default, recommended)
cmake -S . -B build -G Ninja

# Unix Makefiles
cmake -S . -B build -G "Unix Makefiles"

# Visual Studio (Windows)
cmake -S . -B build -G "Visual Studio 17"

# MinGW Makefiles (Windows)
cmake -S . -B build -G "MinGW Makefiles"
```

## Using Presets

Instead of long command lines, use CMakePresets.json:

```bash
# Developer debug build
cmake --preset dev
cmake --build --preset dev-build

# CI release build
cmake --preset ci
cmake --build --preset ci-build
```

See [CMakePresets.json](../CMakePresets.json) for preset definitions.

## Common Combinations

### Debug with Sanitizers (development)
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug \
  -DENABLE_SANITIZERS=ON -DBUILD_TESTING=ON
```

### Release with Coverage (CI)
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DENABLE_COVERAGE=ON -DBUILD_TESTING=ON
```

### Strict Mode (CI checks)
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug \
  -DOHC_ENABLE_WERROR=ON -DBUILD_TESTING=ON
```

## Troubleshooting

**"Could not find CMake"**: See [DEPENDENCIES.md](DEPENDENCIES.md)

**"Compiler not found"**: Use
`-DCMAKE_CXX_COMPILER=/path/to/compiler`

**"Ninja not found"**: Install ninja or use
`-G "Unix Makefiles"` instead

**"GoogleTest download failed"**: Check internet; use
`-DFETCHCONTENT_QUIET=OFF` for verbose output

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for more issues.
